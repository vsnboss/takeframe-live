# TAKEFRAME website positioning v1

Static HTML/CSS/JavaScript implementation of the Football Broadcast Operations positioning.

## Routes
- `/`
- `/operator-gear/`
- `/pilot/`
- `/privacy/`

## Current truthful limits
- NORDIC1 is labelled IN DEVELOPMENT.
- NDI output and remote browser control are roadmap items.
- The demo form uses a transparent mailto fallback and does not simulate successful submission.
- No match documents are uploaded through the website.

## Local preview
Run `python3 -m http.server 8080` from the repository root.
