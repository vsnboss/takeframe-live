How it works

Four controlled stages.
One operator workflow.

01 / ONBOARD

Bring the match information.

Match URL, team sheet, PDF, Excel/CSV, player assets, pasted text or manual entry.

02 / PREMATCH

Prepare the football model.

Verify identities, squads, lineups, formations, officials and production data.

03 / MATCH

Operate football events.

Goals, cards, substitutions, VAR, clock, score and match phases from one console.

04 / PROGRAM

Send finished pixels.

Dedicated Program rendering with Preview, alpha and professional IP output over NDI or OMT.

One match model

Four sources in.
One match model out.

Team sheet. PDF. Spreadsheet. Match URL. Screenshot. Manual correction.

TAKEFRAME is built around the match, not around disconnected graphic fields. The operator remains the authority when information conflicts.
