Recommendation, not certification.

These configurations are TAKEFRAME recommendations based on the current local-first architecture. Formal certification will follow repeatable performance testing across defined workloads and hardware combinations.

What matters most

Windows reliability, adequate GPU headroom for browser-rendered graphics, stable storage, dual displays for operator visibility, and a production network appropriate for the chosen OBS or vMix workflow.
