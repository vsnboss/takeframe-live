08PREVIEW · PROGRAM · TAKE

Preview it. Take it.
Update it. Out.

Proper playout, in proper broadcast terms. Nothing reaches air by accident, and the operator can always see what is on it.

PREVIEW

The graphic prepared for inspection before transmission. Clear Preview at any time without touching Program.

TAKE

Move the prepared graphic to Program. One deliberate action, one result.

UPDATE

Change the data of a live graphic without replaying its entire entrance, where the scene supports it.

OUT

Remove the graphic from Program using its normal exit behaviour.

PROGRAM SAFETY

Know what is on air.

The operator decides whether the system is authorised to command Program at all. Disarmed, the live output cannot be casually altered; armed, every take is deliberate. This safety layer is what separates a production system from an overlay application.
